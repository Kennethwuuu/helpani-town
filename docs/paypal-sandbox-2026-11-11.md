## 已验证的捐助主流程

本地服务地址为 `http://localhost:3000`，服务端固定连接 `https://api-m.sandbox.paypal.com`。本次调用了实际 PayPal Sandbox 服务，资金为测试资金，项目、机构及救助进展继续使用演示数据。

| 验证项 | 结果 |
| --- | --- |
| 服务端凭据认证 | OAuth 接口返回 HTTP 200；凭据及访问令牌未写入本记录。 |
| 从原型创建订单 | 支持页面可创建 USD 5.00 沙箱订单并跳转到 PayPal Sandbox。 |
| 买家授权与回跳 | 用户在自己的浏览器完成测试买家付款，服务端记录捕获结果。 |
| PayPal 远端复核 | 只读查询订单 `3M445005RW753251G` 返回 HTTP 200；订单和捕获状态均为 `COMPLETED`，捕获金额为 USD 5.00。 |
| 本地账本核对 | 订单 ID、项目支持引用、捕获 ID、币种及金额与 PayPal 返回结果匹配；SQLite 中该订单为 `completed`。 |
| 已完成订单重复回跳 | 在该付款所属会话中重复访问完成回调，返回 HTTP 303 到支持记录；前后付款记录、订单数量及捕获记录均未变化，该会话保持一笔已完成 USD 5.00 捐助。 |

## 付款提示验证

前端完成提示已改为汇总服务端付款记录。独立手机尺寸浏览器在空账本下访问 `?payment=completed`，实际显示「暂未查到 PayPal 沙箱付款确认记录，请核对下方支持记录。」，账本仍为空，且付款查询参数被移除。

辅助回归共运行 73 项，72 项通过；唯一失败为勋章 PNG 请求超过 5 秒。该资源用例单独重跑通过。未将本轮全量结果记为全部通过。
