# 本轮资产与资料

## 正式运行的虚拟资产

- `public/woodland-scene.js`：本工程程序绘制的分层林地、小熊猫分肢角色、平台与木道。为风格化虚拟场景，不是现场影像。使用本地绘制，不依赖远端图像服务或模型下载。
- `public/companion-scene.js`：独立程序绘制的穿山甲林下、海龟浅湾、分组角色、休息窝/石台与环境反馈；与小熊猫共用镜头和触摸输入。
- `public/woodland.css`、`public/care-species.js`：三物种统一照顾、布置、摄影和相册界面及元数据。
- `public/assets/medals/pangolin-*.svg` 与 `turtle-*.svg`：本工程原创的六枚程序矢量勋章，正式用于巡护收藏和照片角标，不代表现实保护认证。旧三枚小熊猫 PNG 勋章继续使用。
- 照片由运行时真实场景生成，保留玩家布局、镜头与快门姿态；角标注明虚拟场景。

## 保留的原型素材

`public/*-habitat.svg`、`public/*-pet.svg` 与原有故事 SVG 是旧版原型插画。三种伙伴的主照顾页现均使用 Canvas；旧插画保留给缩略图、故事和原型回归。未将这些插画作为真实保育媒体或机构授权素材。

## 未实现的效果

写实毛发、肌肉变形、完整物理与动物碰撞模拟、真实声场、专业角色模型，以及更多未收录物种的动作未在本轮实现。当前是分组程序动画与预设可达路径。
