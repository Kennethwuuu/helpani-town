# 科普问答与勋章照片奖励 · 实现和验证

2026 年 11 月 9 日完成实现与浏览器试玩，11 月 10 日补齐交付说明。

本轮落实[策划评审](quiz-reward-review-2026-11-09.md)中优先改善的答题反馈和勋章获得感。三枚勋章使用新生成的透明底插画，完整提示词与来源见[素材记录](medal-art-prompts-2026-11-09.md)。

## 当前可体验的变化

| 环节 | 玩家看到的反馈 |
| --- | --- |
| 首次答对 | 显示首次掌握印记、正确解释和观察线索；知识册分别记录已发现与已掌握数量 |
| 答错 | 保留见闻和成长，针对所选错误解释误解，再展示正确知识与来源 |
| 累计见闻 | 显示四次见闻的定向领取进度，以及当前可领取次数 |
| 选择勋章 | 三枚插画卡区分未解锁、已拥有和使用中；领取前可查看图案、故事和照片角标用途 |
| 领取勋章 | 新获得时展示奖励揭晓弹窗，可立即用于拍照；刷新或重新装备不会重复播放领奖弹窗 |
| 勋章留念 | 装备后打开当前画面的照片预览，勋章以角标进入照片；预览可移除或切换已有勋章，再保存或下载 |

## 试玩路线

1. 通过本地服务打开 `/woodland`，进入巡护并选择主题。
2. 掷骰遇到问答，分别体验答对与答错。留意首次掌握、错误解释和知识册计数。
3. 累计四次见闻后，在收藏里选择一枚未拥有勋章，查看奖励揭晓，再点立即使用。
4. 在冻结的照片预览中切换角标、调整裁切，保存到相册或下载 1600 × 1000 PNG。
5. 刷新后回看知识与收藏，再从相册打开已保存照片。后续更换装备不会改变旧照片。

问答保留既有奖励规则：答对和答错都记一次见闻，并使用相同的额外发现判定；每四次见闻获得一次定向领取机会。见闻总数不扣除，三枚勋章不重复领取。勋章装备只接受已拥有的项目，不改变骰子、木道、照护、公益积分或支付记录。

## 当前边界

同一次事件的答案结算后不能重答；独立练习、变式题、拖拽互动、音效及设施皮肤留待后续。知识册保存曾经答对的掌握状态，后续巡护仍可遇到并学习已有题目。

照片保存在当前浏览器的 IndexedDB，没有跨设备相册；请保持同一网站地址并下载需要保留的照片。三枚透明 PNG 原图各约 2.3–2.8 MB，卡片使用延迟加载，公开发布前仍可优化资源体积。
