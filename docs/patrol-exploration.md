## 玩法定位

参考本次讨论中描述的“掷骰 → 沿格子地图移动 → 遇到事件 → 选择 → 获得动物勋章或故事”，增加一条轻量巡护探索路线。小镇负责陪伴、照护与摄影，巡护负责发现、选择与收藏，两者共享物种档案、故事册和虚拟成长结果。

地图上移动的是玩家的巡护标记。动物在各自的生活场景中继续按习性自主活动；到达观察点时，可以进入相应栖地观看和拍照。巡护事件带来新的故事、观察主题和场景内容，使玩家回到小镇后有新的事情可做。

## 一次巡护的流程

1. **选主题与本期期待**：带着“想认识竹竹的生活”或“想了解森林保护”的目标出发，回看已学知识与收藏。
2. **掷骰**：使用一次免费巡护机会，获得步数；地图上可看见剩余路线及格子类型。
3. **移动**：巡护标记逐格行进，场景随之展开，到达目的格后停下。
4. **猜一猜**：结合林地情境，在三个答案中选择自己的猜测。
5. **发现新知识**：看正确答案、解释、资料来源及回家观察提示，答错也有完整反馈和见闻。
6. **收藏与回访**：知识册可复习，结果卡可直接继续掷骰，也可带着观察线索回到竹竹身边拍照。

本轮每次路线提供八次免费机会，路线完成后可主动重新巡护，已有故事、勋章与设施持续保存。后续公开版本的日常补充节奏与可保留次数在玩家试玩后另定。巡护机会、游戏成长、公益积分和真实支持记录各有清楚名称与用途。

## 地图上的格子

地图表现为穿过林地、溪边与巡护站的可读路线。地形和节点有环境层次，格子边界与步数保持清楚。

当前普通格统一打开科普题，位置不绑定唯一题目，避免重访只见相同内容；下面是后续扩展的格子方向，尚未实现独立支线场景。

| 格子 | 事件或互动 | 与原有体验的连接 |
| --- | --- | --- |
| 动物观察点 | 观察一个日常行为，选择等待、记录或进入栖地拍照 | 新观察条目、个体日常和摄影题材 |
| 栖地工作点 | 在两种合理的环境维护或设施布置方案中选择 | 虚拟设施内容、栖地故事与布置灵感 |
| 巡护站 | 阅读角色来信、整理见闻或查看已获得的收藏 | 故事册与成长日记；真实机构内容使用独立入口 |
| 偶遇点 | 遇到动物踪迹、天气变化或巡护员小故事 | 分支故事、额外动物勋章或新的观察线索 |
| 路线里程碑 | 到达或经过指定位置后记下进度 | 确定获得的主线故事与完成纪念，支持稳定推进 |

普通事件在落格时触发。里程碑在到达或越过时记录，避免掷骰跨过后遗漏主线；一次掷骰最多打开一个需要选择的事件，里程碑内容可以稍后在手记中阅读。

## 一个问答例子：树枝上的大尾巴

情境是虚构的竹影林，知识来自题目所附的机构资料。

> 竹竹走上细细的枝杈，尾巴轻轻摆动。小熊猫长而蓬松的尾巴，在树上主要能帮什么忙？

| 作答 | 可见结果 | 收藏与后续 |
| --- | --- | --- |
| 猜中答案 | 显示确认、解释、资料链接和观察提示 | 收录知识页与本次见闻；可回同一林地观察尾巴随动作的变化 |
| 猜错答案 | 保留当次猜测，同时给出正确结论与解释 | 同样收录知识、累计见闻与额外机会，后续巡护可以重新认识这题 |

题目只占一次落格见闻，选择答案不额外消耗掷骰次数。回林地不会移动巡护标记或命令动物动作；观察提示帮助玩家带着问题等待真实游戏行为。[习性资料](https://nationalzoo.si.edu/animals/red-panda)

## 随机惊喜与稳定成长

| 内容 | 获得规则 | 重复时怎样处理 |
| --- | --- | --- |
| 科普知识与巡护见闻 | 完成题目即记当次作答，正确结论与来源进入知识册 | 新访问继续累计手记，知识页按题 ID 去重；重复答对只更新曾答对状态 |
| 主线动物故事 | 路线里程碑确定解锁，故事册展示已读与待解锁章节 | 已读章节可重看，继续向下一个未完成里程碑推进 |
| 分支故事与动物勋章 | 事件中有机会额外获得；选择结果展示对应的奖励范围 | 优先选择尚未获得的内容；重复发现计入物种的累计观察进度 |
| 定向收藏进度 | 累积同物种事件记录达到公开目标后，可以选择一项该物种未获得的分支故事或勋章 | 已集齐时展示完成状态，后续记录继续进入日记 |
| 栖地与摄影内容 | 根据路线或故事完成进度解锁少量虚拟设施内容、相册封面或边框 | 已拥有内容保留，改为展示新的使用和拍摄主题 |

本轮在收藏与见闻中保留获得记录，公布 25% 额外发现机会和四次事件的定向收藏目标。徽章进入相册纪念页、分享图及更多分支故事是后续目标；数值调整需同步更新界面和本文，随机分布与奖励文本应一致。

这套设计让每次巡护留下进度，同时保留“这次会遇见什么”的期待。故事可以回看，勋章可以定向补齐，摄影与场景内容把巡护结果带回动物生活空间。

环境布置作为核心养成后，路线的阶段收获优先连接一项能实际使用的栖地内容：完成章节或相关游戏目标后确定解锁，回小镇预览位置、保存布置，再观察动物的自主回应。首件设施在小镇首访赠送；之后的游戏观察、照护与巡护章节共同推进设施成长，额外外观或纪念内容可作为偶遇奖励。完整交互与验收见 [环境布置规格](animal-life-experience.md#环境布置作为核心养成)。

## 与真实保育项目的关系

巡护得到的是虚拟见闻、故事、勋章和游戏内容。公益积分继续来自活动核验，真实捐款和项目成果继续使用支付记录与机构证据。游戏里的路线完成与动物偶遇记录进入巡护手记。

合作机构提供的照片、视频和真实巡护日记可在巡护站的“现场手记”独立展示，标出日期、提供机构、项目及资金用途或执行记录。与虚构事件有关联时，可以解释灵感来自哪个真实项目，现实工作进展仍以机构报告为准。

## 小样范围与验收

本轮在生活、布置和摄影第一关通过后接入巡护，并迭代为：**一条林地路线、8 个可前进格与一个起点、1 枚 1–6 点骰子、6 道三选一问答、知识册、2 段主线、少量动物勋章和一件连接木道**。以下为验收要求，新问答通过状态和证据见 [验收记录](patrol-quiz-2026-11-09.md)。

| 项目 | 小样规则或验收 |
| --- | --- |
| 路线推进 | 从已保存的位置前进，达到或越过末格即完成本次路线；步数超过剩余距离时停在终点 |
| 逐格反馈 | 掷骰结果、标记移动和最终位置一致；玩家能看清走了几格、为什么触发当前事件 |
| 科普作答 | 选前不泄露答案，选后能理解正确结论及原因；错误答案不作为知识结论保存，解释与来源可回看 |
| 动物观察 | 至少一个观察点能进入同一个自主生活场景，并能拍摄和保存照片 |
| 稳定成长 | 路过里程碑也能取得主线进度；定向收藏有明确目标，重复奖励有可见用途 |
| 中途退出 | 刷新或重进后，位置、已掷结果、待完成事件和已获得内容可恢复；重试操作不重复耗次数或发奖励 |
| 路线重访 | 完成后可回顾或主动再次巡护；保持已获得的故事、勋章和小镇成长 |
| 复盘重点 | 玩家是否期待下一次掷骰、是否关心事件选择、能否记住故事，以及是否会回栖地观察和拍照 |

下一轮先根据实际试玩处理移动可读性、选择差异和木道反馈，再评估更多地图、内容和日常补充节奏；技术通过不等于已经验证玩家回访动机。
