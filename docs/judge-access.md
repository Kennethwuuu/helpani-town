# Judge access

Open [Helpani Town](https://vibecreating.tech). The game and organizer demo require **no account, installation, payment, or personal API key**. A fresh browser defaults to English. Use **Language / 语言** in the header to switch to Chinese or English; the choice is saved in that browser.

Progress belongs to this browser's 30-day demo session. Use the same browser and hostname for the walkthrough. A private window starts a separate session. Photos remain in the current browser and can be downloaded.

## AI drafting

The hosted server supplies its own Astropods access. Open `/project-draft`, select sources, and generate a draft in the current interface language. Changing language clears a previous draft and retains source selections, so a new draft can be generated in the selected language. All drafts require human review and are not published game tasks.

The hosted allowance is 100 actual Gateway attempts globally, 10 per browser session, and one concurrent generation. Format retries and upstream failures consume attempts. Counters do not reset automatically. If the service is busy or exhausted, source reading and deterministic budget checking remain usable.

## Optional PayPal checkout

The owner has selected an **existing PayPal Sandbox Personal buyer account** for judging. The owner will enter its login email and password in the event's **private judge/testing instructions**. Those values are deliberately absent from this public guide and repository. Providing those two private fields is the remaining owner handoff; this document does not claim they have been submitted.

1. Open `/support` in the same browser. Expand **PayPal Sandbox contribution**, choose USD 5, 10 or 20, and continue to PayPal Sandbox. Alternatively choose the USD 8 specified-material checkout.
2. Sign in using the Sandbox buyer supplied privately. Test funds are used; no real payment is needed. Do not use a live PayPal account or the developer/seller login.
3. Review the amount and return to Helpani Town after authorization, or cancel and return. The app creates and captures test orders on its server.
4. Read **My records**. A confirmed test payment is separate from purchasing, delivery, or any rescue outcome.

The existing hosted USD 5 return/capture has been checked; that evidence predates the language release. Final private-field entry and a judge's fresh-session login remain to be confirmed. PayPal's own pages control their language and sign-in behavior. See [official Sandbox account documentation](https://developer.paypal.com/sandbox-testing/accounts).
