## 核心方向

把小镇做成玩家愿意探望、照护和拍照留念的动物生活空间。动物在符合物种习性的救助中心或自然栖地里自主活动，玩家通过照护、环境布置和持续观察认识它，逐步积累共同经历。照片、相册与自愿分享让这些经历能被保存和传播；真实机构的图文、视频与项目执行记录，让玩家继续了解现实中的保护工作。

核心体验假设是：玩家牵挂某只动物，期待看到它的新日常和自己的布置带来的变化，因此主动回来；遇到喜欢的瞬间，会愿意拍照并分享。这个假设需要由可玩小样与真实玩家反馈验证。Planet Zoo 是动物与栖地关系的参考，首轮范围是一只动物和一个精细场景。

本次确认将环境布置作为核心养成：玩家先认识伙伴的日常，再选择想改善或探索的生活细节；巡护带回故事与布置灵感，回到栖地后能看见自己的选择被动物实际使用，最后拍照留下共同经历。

现有三种伙伴、喂食、XP、手记、模拟活动和支持记录继续保留。自主生活、布置与摄影现已覆盖三种伙伴；更多物种、正式机构更新和分享传播仍按下列长期目标扩展。建设、观察与巡护记录使用独立虚拟成长，不改动原有照护 XP、公益积分与支付账本。

## 四个相互连接的玩法循环

| 循环 | 玩家做什么 | 可观察的反馈 | 再次回来的期待 |
| --- | --- | --- | --- |
| 当次探望：观察与照护 | 找到动物，观察状态，做一次照护或环境调整 | 动物注意到变化，自主接近、探索或继续休息；镜头与声音呈现反馈 | 想看看它接下来会做什么 |
| 跨日养成：栖地与共同经历 | 逐步布置适合物种的设施，记录不同日常，解锁照护故事 | 新设施能被动物实际使用；出现新的活动组合，观察册留下已见行为与照片 | 想看看昨天的布置如何被使用，发现新的个体习惯 |
| 留念与传播：拍照和相册 | 等待喜欢的瞬间，调整构图，保存照片，选择分享 | 得到能独立欣赏的照片；相册记录伙伴、场景和拍摄日期 | 想补齐日常观察、拍到新的场景，或向朋友展示自己的小镇 |
| 巡护与发现：掷骰和问答 | 沿路线前进，结合情境猜测动物习性或保护知识 | 答案、解释和来源留在知识册；观察线索带回栖地；里程碑稳定推进主线 | 想认识新的小知识，带着线索观察，并留下自己的照片 |

真实保育更新作为持续内容接入以上循环：读一条现场日记，了解一个项目需求，选择参与或支持，之后收到机构确认的执行记录与后续进展。玩家可持续完成虚拟养成和摄影；真实支持由玩家自主选择。

巡护地图上移动的是玩家的标记，动物生活场景持续保留自主行为。新增巡护小样在动物生活与摄影小样之后验证，具体规则见 [掷骰巡护与事件收藏](patrol-exploration.md)。

## 动物自主生活

行为选择共同考虑物种习性、游戏内时间、当前状态、个体偏好和环境。动物有能抵达的活动区域，移动、观察、停下、使用设施与休息之间有连贯过渡。照护会影响它接下来的选择，反馈允许有自然的等待与差异。

| 层面 | 体验要求 |
| --- | --- |
| 物种习性 | 各物种分别定义作息、移动方式、可使用的环境设施和典型行为 |
| 个体差异 | 同物种也有偏爱的地点、探索节奏和设施选择，玩家可以逐渐发现 |
| 环境关系 | 树枝、水池、洞穴等是动物实际使用的空间；设施改变后，活动选择随之变化 |
| 动作连续性 | 行走、转身、停顿与下一动作能衔接；接触面、遮挡、重心和声音一致 |
| 离线与回访 | 已解锁的设施、故事和相册持续保留；回来可以看到新的生活状态或已记录的活动片段 |

首个场景已选择小熊猫林地，围绕“地面探索 → 攀爬 → 选择枝杈 → 树上休息”做完整体验。小熊猫擅长攀爬、晨昏更活跃，休息姿势也会随温度变化；这些事实可以指导行为与场景设计。[Smithsonian 物种资料](https://nationalzoo.si.edu/animals/red-panda)

救助中心场景还应结合个体年龄与康复阶段设定活动范围。虚拟场景可以明确采用压缩的游戏作息；现实动物的状态随机构报告更新。休息或躲藏时仍能观察环境、整理相册、看已记录片段。缺席后保留成长进度，回访时可直接恢复探望。

## 环境布置作为核心养成

玩家的长期目标围绕“让这片生活空间逐渐成为我和伙伴共同经历的地方”展开。重要的布置内容要带来动物可使用的空间、不同的活动路线或新的观察位置。植物、光影与装饰同时形成玩家自己的照片风格。

| 内容方向 | 玩家选择 | 可观察的游戏反馈 | 范围 |
| --- | --- | --- | --- |
| 树边休息平台 | 在两个可达位置中选择：靠近树干，或朝向较开阔的林缘 | 动物到达平台的路线、停留位置和摄影背景不同；自主决定何时查看或休息 | 第一关已实现，验证见试玩记录 |
| 攀爬连接设施 | 巡护获得连接木道后，在一个预设连接位预览并确认 | 动物新增树冠路线和穿行机会，玩家可拍摄新行为 | 本轮第二关接入，验证见试玩记录 |
| 林下植物组 | 选择预设的植物组合与可摆放区域 | 形成不同的遮挡、观察角度和可探索边缘 | 后续候选，需验证视线与可达空间 |

以上为虚拟场景设计；正式设施和行为仍按物种资料、个体设定与合作方资料复核。每项设施分别说明“它能带来什么生活变化”，并展示放好后的大致尺度和位置。

首轮采用预设摆放点，优先做精一次完整选择：

1. **选择设施**：看清用途、已拥有状态和可用位置。首件休息平台在首次探望赠送。
2. **预览位置**：点选两个有效位置之一，预览大小、相邻路径和镜头效果；可切换位置比较，也可取消。
3. **确认布置**：确认后保存布局。正在被动物使用的设施在当前动作结束后更新，界面显示已保存、待生效，玩家可以继续观察或离开。
4. **观察回应**：动物可以转向查看、接近探索、使用或稍后再来；观察册逐渐记录它偏好的位置。布置的成长进度在保存成功时确认，首次使用另留一条共同经历。
5. **拍照与再次调整**：玩家保存喜欢的瞬间，之后可免费移动已有设施，比较新位置带来的活动与构图变化。

首轮的设施用途是增加可选择的生活内容；动物的基础休息和活动空间从一开始就存在。新设施逐步解锁，已有设施随时可回看与重新安排，玩家的成长保留在布局、故事和观察记录中。

| 布置验收 | 要确认的结果 |
| --- | --- |
| 位置确有差别 | 两个摆放点带来可见的到达路线或摄影构图差异 |
| 预览与确认一致 | 保存后的尺寸、方向和位置与预览相符；取消后原布局保留 |
| 自主选择有反馈 | 动物能到达并使用设施，使用前后有完整动作；玩家能理解它当前在做什么 |
| 等待可被理解 | 保存成功和动物首次使用分别反馈；不要求等到指定随机动作才取得布置进度 |
| 重进与移动可靠 | 刷新后恢复已保存或待生效的安排，重复确认只保留一份布局和一次解锁 |
| 摄影可用 | 两种布局都能找到清楚的取景角度，已保存照片保持原画面 |

巡护的阶段奖励优先选择一项能回到栖地使用的布置内容。玩家可先选择“想为伙伴找一个新的休息角落”等探索主题，再掷骰遇事。基础设施解锁有明确的观察、照护或章节完成路径，额外款式和特殊纪念内容可以作为偶遇奖励。具体地图连接见 [巡护探索规格](patrol-exploration.md)。

## 摄影与自愿分享

照片的内容来自动物生活：新设施第一次被使用、独特睡姿、动物经过前景、光影变化，以及玩家逐渐形成的小镇布置。观察本身能提供拍摄题材。

本轮摄影包括收起界面、移动与缩放镜头、静态裁切、预览、保存、相册回看和下载，成片固定为 1600×1000 PNG。快门冻结当时姿态与玩家布局，相册与下载使用同一成片；照片仅保存在当前浏览器，清除网站数据会丢失。景深对焦、竖屏与方形构图、文字手记、系统分享和回访链接为后续目标。未来分享仍由玩家主动确认，实际发布由玩家完成。

本轮导出保留“小熊猫 · 竹竹”和“小镇影像 · 虚拟场景”两个简洁角标，账号信息与支付记录不进入照片。昵称开关及照片成就是后续目标；同一快门重复保存只留一条记录，另一次快门可保存为新的收藏。

后续主题活动可围绕栖地与观察展开，例如雨后林地、清晨探望、设施初体验。拍到的照片进入玩家自己的日记；分享作为可选出口。是否愿意主动保存或分享，以及具体喜欢哪一个瞬间，是试玩访谈的重点。

## 与真实保育工作的连接

动物档案可关联一个真实合作项目。有明确个体资料与授权时，再建立虚拟角色与真实动物的对应关系；项目级合作展示“这位伙伴所代表的保护项目”。

| 更新类型 | 需要呈现的内容 | 玩家理解到什么 |
| --- | --- | --- |
| 项目需求 | 负责机构、当前需求、预算用途与阶段目标 | 为什么需要支持，支持将用于哪里 |
| 支付与资金进展 | 回执、资金状态、机构确认的用途与执行记录 | 一笔支持目前走到了哪一步 |
| 现场图文或视频 | 拍摄日期、提供方、相关活动或项目、发生了什么 | 现实工作怎样开展，与本期支持有什么关系 |
| 阶段成果 | 机构说明、可公开证据、后续安排 | 哪些工作已完成，哪些还在继续 |

支付、采购或活动执行、康复与放归分别更新。媒体说明现场情况，执行记录说明资金用途；公开内容按机构可持续提供的节奏发布。现场材料由机构提供并审核，游戏画面与生成式素材只用于虚拟体验和明确标注的演示。

收到真实更新后，小镇可以解锁相应的照护故事、项目纪念册或已确认的阶段介绍。虚拟成长按游戏规则继续，现实成果采用机构确认的进展与归因范围。

## 首个可玩小样与后续顺序

本轮先交付“一只小熊猫、一个林地场景、一件平台的两个位置、一套观察册、一个摄影出口”，通过实际试玩后接入巡护与木道。既有项目更新继续标为演示，未新增真实机构媒体或成果声明。下表保留体验验收框架，实际通过项以 [试玩记录](playtest-2026-11-08.md) 为准；环境声与正式项目叙事仍待后续工作。

| 顺序 | 交付 | 体验验收 |
| --- | --- | --- |
| 1 · 视觉与动效小样 | 同一场景的角色、地形、光影、遮挡、环境声与完整动作片段 | 能看清动物的体积、重心、落点与活动空间；据此确定 2.5D 或轻量 3D 的资产形式和工期 |
| 2 · 动物生活 | 探索、攀爬、树枝休息等可衔接行为；同一设施有选择和反馈 | 玩家可以先观察，随后通过一次环境调整看到动物自主响应；不同探望出现合理变化 |
| 3 · 小份养成 | 一个设施的获得与布置、观察条目和一段成长日记 | 下一次进入保留成长结果，能看出自己的选择如何影响生活空间 |
| 4 · 摄影 | 收起界面、构图、预览、下载与相册回看 | 图片清晰、构图可用、无界面遮挡；预览、导出与再次打开的内容一致 |
| 5 · 真实项目叙事 | 一个项目的用途、带来源的图文或视频更新、阶段记录 | 玩家能复述支持用途、目前进展与待完成事项，分清虚拟场景和现场内容 |

首轮先区分首访引导与自由操作，分别记录引导中的拍照完成和自由阶段或后续回访中的主动拍摄、导出。观察玩家是否会停下来观看、记住一个个体习惯，以及能否说出下一次想回来看的内容；回访时追问期待是否得到回应。小样验证摄影导出体验和分享意愿，实际社媒发布、朋友访问与传播效果在对应功能接入后另行验证。依据这些反馈再决定增加物种、设施、社交访问与主题活动的顺序。

现有参赛流程继续按 [MVP](mvp.md) 交付。新的动物生活小样先验证表现力、玩法反馈和回访动机，再据资产制作与试玩结果重估公开玩法版本工期。

## 首次探望怎样展开

以下是小样的交互顺序，时长与奖励数量属于待试玩调整的设计参数。

| 时刻 | 玩家看到与做出的选择 | 动物与场景反馈 | 完成后留下什么 |
| --- | --- | --- | --- |
| 进入林地 | 先看见场景和动物，能拖动或缩放视角；需要时点“找找伙伴” | 镜头引向动物当前位置，能观察它正在探索或休息 | 对这只伙伴和活动空间的第一印象 |
| 发现日常 | 自由观察竹竹的活动，本轮在首次出现相应行为时自动记录 | 观察册展示已见行为与日期，物种说明保留资料来源 | 第一条观察记录；保留继续观看的入口 |
| 做一次布置 | 用小样赠送的一件休息平台，在两个可达的预设位置中选择一个 | 平台进入场景；动物根据当前状态注意、接近、查看或使用，也可能稍后再来 | 玩家自己的场景布局，以及对后续反馈的期待 |
| 看见回应 | 跟随动物或等待，观察它怎样探索新环境 | 通过转身、停步、查看设施与动作衔接表现选择过程；初次体验有机会较快看到反馈 | 新的观察内容与一个可拍摄瞬间 |
| 拍下喜欢的画面 | 主动打开相机，收起界面，调整构图并拍摄 | 进入当前画面的静态预览，允许调整裁切、保留或重拍 | 一张本次探望的照片 |
| 留下回访线索 | 保存到相册并下载照片，可继续查看观察册与已有演示项目更新；文字手记后续再加 | 显示这次布置和已发现的日常，提示后续还能观察的生活细节 | 相册、布局和观察进度持续保留 |

初次布置使用赠送设施，让玩家当次体验到“我的选择影响了场景”。动物有可达路线与可用设施，试玩时需确认等待反馈的时间能被接受。用户也可先拍照、后布置，或只观察。

## 前三次探望的养成节奏

| 探望 | 一个主要期待 | 成长内容 |
| --- | --- | --- |
| 第一次：认识它 | 我想知道它平时怎样生活 | 看到一段完整行为，完成首次布置，保存第一张照片 |
| 第二次：认出习惯 | 我想看看它用了昨天的平台没有 | 原布局保留；出现合理的新状态，可补记不同日常、回看旧照片和记录偏好 |
| 第三次：做出自己的小镇 | 我想让这里更有自己的样子 | 本轮可调整平台、通过巡护扩展木道并用同一机位回看变化；观察解锁摄影装饰是后续目标 |

“前三次”可以在不同日期发生，也可用明确标为演示的游戏时间加速体验。小样把一种设施的两个摆放位置做清楚；更多设施、成长阶段和主题活动根据复访反馈扩展。再次进入时照护与观察随时可继续，保留已完成的成长。

## 摄影状态与验收细节

| 状态或操作 | 期望行为 |
| --- | --- |
| 观察中打开相机 | 收起任务与资金界面，保留必要取景操作；动物在场景里继续生活 |
| 按下快门 | 捕获玩家取景时的画面，进入静态预览，允许慢慢裁切与选片 |
| 重拍或取消 | 返回原场景与当前动物状态，已保存的照片和养成进度保留 |
| 保存与再次查看 | 相册展示这次拍摄的同一画面、动物名、日期和可选手记；重复点击只生成一条保存记录 |
| 下载 | 导出与预览构图、清晰度一致的图片，动物主体不被角标遮挡 |
| 保存或下载失败 | 预览仍可查看，提供重试，玩家可以安全返回场景 |
| 后续分享入口 | 先展示实际将分享的图片和可选文字，玩家主动选择目标并完成发布；取消后回到照片 |

照片的吸引力优先来自动物姿态、环境层次和玩家布置。镜头要能覆盖动物常用的地面和树上位置，照片可容纳完整身体或明确的特写；在小屏幕也能完成取景、预览和保存。首轮不依赖外部社媒账号即可验证摄影与下载体验。
